# Production Readiness Scorecard

Status values: `PASS`, `CONDITIONAL`, `BLOCKED`, `NOT_STARTED`.

Launch blocker values: `[BLOCKER:P0]`, `[BLOCKER:P1]`, `P2`, or `None`.

| Area | Owner | Status | Risk | Validation command | Launch blocker | CI artifact |
|---|---|---|---|---|---|---|
| Security | Security Engineering | CONDITIONAL | Auth, RBAC, secret hygiene, supply-chain, and security regression evidence must remain current before launch. | `pnpm test:security` | [BLOCKER:P0] if failing or missing evidence | [PR Checks / structural-check-reports](../.github/workflows/pr-checks.yml), [Zero Trust Validation / artifacts/zero-trust](../.github/workflows/zero-trust-validation.yml), [Audit Evidence / complete-audit-evidence-bundle](../.github/workflows/audit-evidence.yml) |
| Reliability | Platform Engineering | CONDITIONAL | Golden path, queue topology, live workflow, and release smoke failures block production confidence. | `pnpm test:queues` and `python scripts/ci/generate_launch_evidence_bundle.py --artifacts-only --up-to-stage staging` | [BLOCKER:P0] if core services or golden paths fail | [Launch Readiness / launch-evidence-bundle](../.github/workflows/launch-readiness.yml), [Backend Integrated Reproducibility / artifacts/live-workflow-validation](../.github/workflows/backend-integrated-reproducibility.yml) |
| Observability | SRE | CONDITIONAL | Missing telemetry, alert metadata, SLO burn-rate alerts, or receiver evidence delays launch operations. | `pnpm test:observability` and `pnpm lint:logs` | [BLOCKER:P1] if alerting or dashboards lack evidence | [PR Checks / artifacts/observability](../.github/workflows/pr-checks.yml), [Game Day Evidence / artifacts/obs](../.github/workflows/game-day-evidence.yml) |
| DR | SRE | CONDITIONAL | Backup existence is insufficient without restore dry-run evidence and rollback verification. | `pnpm ops:backup:verify` and `pnpm ops:restore:dry-run` | [BLOCKER:P0] if restore or rollback evidence is absent | [DR Drill / restore evidence artifacts](../.github/workflows/dr-drill.yml), [Deploy / evidence artifact](../.github/workflows/deploy.yml) |
| Release Safety | Release Engineering | CONDITIONAL | Deployment, rollback, branch protection, immutable image, SBOM, and policy gates must be current. | `pnpm release:dry-run` and `pnpm release:rollback:verify` | [BLOCKER:P0] if release gates or rollback verification fail | [Critical Gates / artifacts/critical-gates](../.github/workflows/critical-gates.yml), [Deploy / evidence artifact](../.github/workflows/deploy.yml), [Environment Promotion / artifacts/build-metadata](../.github/workflows/environment-promotion.yml) |
| Billing | Product Engineering | CONDITIONAL | Paid launch requires metering, entitlement, webhook, idempotency, and reconciliation evidence. | `python scripts/ci/generate_billing_evidence.py --help` | [BLOCKER:P1] for paid GA; scope out if no paid launch | [PR Checks / launch-checklist-billing-entitlements-evidence artifact](../.github/workflows/pr-checks.yml) |
| Tenancy | Platform Security | CONDITIONAL | Cross-tenant access, unscoped queries, route propagation, and tenant bypass regressions block launch. | `pnpm test:isolation` | [BLOCKER:P0] if tenant isolation gate fails | [PR Checks / tenant-isolation-gate-summary](../.github/workflows/pr-checks.yml), [PR Checks / route-tenant-propagation artifacts](../.github/workflows/pr-checks.yml) |
| Data Lifecycle | Data Platform | CONDITIONAL | Ingestion provenance, retention, backup, restore, migration, and deletion semantics need retained evidence. | `pnpm db:migrate:check` and `make check-migration-heads` | [BLOCKER:P1] if migration or retention evidence is stale | [PR Checks / migration and structural artifacts](../.github/workflows/pr-checks.yml), [K8s Validation / artifacts/k8s-validation](../.github/workflows/k8s-validation.yml) |
| Compliance Evidence | Compliance Owner | CONDITIONAL | SOC2/ISO-style controls need owner signoff, audit snapshots, access review, and evidence retention. | `python scripts/ci/validate_production_readiness_plan.py` | [BLOCKER:P1] if control ownership or retained evidence is missing | [Audit Evidence / complete-audit-evidence-bundle](../.github/workflows/audit-evidence.yml), [Audit Snapshot / artifact](../.github/workflows/audit-snapshot.yml) |

## Launch Review Rule

Production launch requires scorecard review. The launch reviewer must record the current status of every row, attach the latest CI artifact links or run IDs, and confirm that all `[BLOCKER:P0]` and `[BLOCKER:P1]` rows are resolved, waived, or explicitly excluded from scope.
