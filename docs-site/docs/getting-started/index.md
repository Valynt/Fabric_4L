## The value workflow at a glance

ValuePact is organized around a progressive workflow that moves a prospect account from raw
signals to a packaged, defensible business case:

1. **Accounts** — select or create a prospect account.
2. **Intelligence** — discover signals, drivers, evidence, and stakeholders.
3. **Value Studio** — synthesize an action plan, value model, and narrative.
4. **Deliverables** — package outputs (business cases, CFO / executive / technical views).
5. **Governance** — review audit trails, provenance, and compliance.

Supporting these are the **Context Engine** (value packs, models, formulas, agents) and
**Settings** (tenant configuration, integrations, team, and billing).
