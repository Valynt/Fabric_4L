# Quick Start Guide

This guide walks through a first end-to-end pass: from signing in to producing a business case.

## Purpose

Get a new user to their first packaged deliverable quickly.

## Audience

- End user
- Admin

## Prerequisites

- An invitation to a ValuePact workspace (organization).
- A signed-in session. ValuePact supports SSO and multi-organization selection on sign-in.

## Steps

1. **Sign in and choose a workspace.** After authenticating, select your organization
   (workspace). New users may be guided through onboarding.
2. **Open Accounts.** From the left rail, open **Accounts** and select an existing prospect
   account or create a new one.
3. **Gather Intelligence.** In the **Intelligence** workspace, work through the tabs:
   **Signals → Drivers → Evidence → Stakeholders**.
4. **Build the value model in Value Studio.** Move to **Value Studio** and progress through
   **Action Plan → Value Model → Narrative**, using the calculator and driver tree as needed.
5. **Package Deliverables.** Open **Deliverables** to generate a business case and the
   CFO, executive, or technical views for sharing.
6. **Check Governance.** Review the audit trail, provenance, and compliance status for your
   work in the **Governance** domain.
