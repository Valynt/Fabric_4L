# What is ValuePact?

ValuePact helps revenue and value teams define, forecast, track, and report business value
across prospect accounts. It turns scattered signals and assumptions into a defensible,
governed value model and a set of shareable deliverables.

## Purpose

Use this page to understand what ValuePact is, who it is for, and the core ideas behind it.

## Audience

- Executive
- End user
- Admin

## What ValuePact does

- **Captures intelligence** about an account — signals, value drivers, supporting evidence,
  and stakeholders.
- **Builds value models** — driver trees, formulas, and ROI calculations grounded in
  reusable variables and benchmarks.
- **Produces deliverables** — business cases and tailored CFO, executive, and technical views.
- **Governs the work** — every output is traceable through audit logs, provenance, and
  compliance controls.

## How it is organized

ValuePact presents seven navigation domains in the left rail: **Accounts**, **Intelligence**,
**Value Studio**, **Context Engine**, **Deliverables**, **Governance**, and **Settings**.
Capabilities are progressively disclosed by tier (Standard, Advanced, Admin) so business users
see simplified flows while power users and admins gain modeling and configuration tools.

## Industry value packs

ValuePact ships with industry value packs — for example **Manufacturing**, **AI / Data
Platform**, and **Financial Services** — that enable relevant formulas, templates, variables,
and benchmarks for a workspace.
