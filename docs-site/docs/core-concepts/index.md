# Core Concepts

Core concepts explain the building blocks of the ValuePact value workflow and how they connect
across the Intelligence, Value Studio, and Deliverables workspaces.

## In this section

- **Value Realization** — tracking forecasted value through to realized outcomes.
- **Business Cases** — packaged, defensible value arguments produced as deliverables.
- **ROI Calculations** — calculator-driven return analysis built on drivers and formulas.
- **Benefits Tracking** — monitoring expected versus achieved benefits.
- **Stakeholders** — the people and roles mapped during discovery.
- **Value Metrics, Outcomes, Forecasts, Actuals** — the measurement layer behind value models.

## How the concepts fit together

1. During **Intelligence**, you capture **signals**, identify **value drivers**, attach
   **evidence**, and map **stakeholders**.
2. In **Value Studio**, drivers and **formulas** feed **ROI calculations** and a **value model**,
   which is expressed as a **narrative**.
3. In **Deliverables**, the model becomes a **business case** with CFO, executive, and technical
   views.
4. **Forecasts** set expected value; **actuals** capture realized value; **value realization**
   compares the two over time.
