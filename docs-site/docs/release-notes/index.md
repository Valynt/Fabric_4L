## Release cadence

| Type | Frequency | Notice |
|------|-----------|--------|
| Major | Quarterly | 30 days advance notice |
| Minor | Bi-weekly | In-app notification |
| Patch | As needed | No advance notice |
| Hotfix | As needed | No advance notice |

## Release categories

- **New Features** — New capabilities and major enhancements
- **Enhancements** — Improvements to existing features
- **Fixes** — Bug fixes and issue resolutions
- **Deprecations** — Features being phased out with migration guidance

## Reading release notes

Each release note includes:

- **Version number** and release date
- **Change category** (feature, enhancement, fix, deprecation)
- **Impact level** (breaking, significant, minor)
- **Affected areas** (UI, API, integrations, security)
- **Migration steps** (if applicable)
- **Known issues** (if any)
