## General troubleshooting process

1. **Identify the symptom** — What exactly is happening? When did it start?
2. **Check the status page** — Visit [status.valuepact.ai](https://status.valuepact.ai) for known incidents.
3. **Review recent changes** — Did anything change recently (role, integration, configuration)?
4. **Gather evidence** — Screenshots, error messages, request IDs, timestamps.
5. **Follow the relevant guide** — Use the articles above for specific issues.
6. **Contact support** — If the issue persists, open a ticket with all gathered evidence.

## Information to include when contacting support

- Your organization (tenant) name
- User email and role
- Exact error message or screenshot
- Request ID (from API responses or browser network tab)
- Timestamp (with timezone)
- Steps to reproduce
- Browser and OS (for UI issues)
