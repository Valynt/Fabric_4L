# Beginner Learning Path

Get from first login to your first business case in under 3 hours.

## Who this is for

<span class="vp-badge vp-badge--role">End User</span>
<span class="vp-badge vp-badge--role">New User</span>

## Prerequisites

- ValuePact account with active organization membership
- Basic understanding of your organization's value framework

## Learning objectives

After completing this path, you will be able to:

- Navigate the ValuePact platform confidently
- Create and populate an initiative
- Build a basic value model
- Generate a business case
- Share deliverables with stakeholders

## Modules

### Module 1: Platform orientation (30 min)

- [Getting Started → Navigating the Platform](../getting-started/navigating-the-platform.md)
- Explore the four workspaces: Intelligence, Value Studio, Deliverables, Governance
- Understand the left rail, top nav, and right rail panels
- Practice switching between organizations

### Module 2: Your first initiative (45 min)

- [User Guides → Creating a Value Initiative](../end-user-guides/creating-a-value-initiative.md)
- Create a new initiative with name, description, and timeline
- Add basic stakeholders
- Set initial status to `draft`

### Module 3: Value modeling (45 min)

- [Core Concepts → Value Metrics](../core-concepts/value-metrics.md)
- [Core Concepts → ROI Calculations](../core-concepts/roi-calculations.md)
- Add 3–5 value drivers to your initiative
- Configure a basic ROI calculation
- Set baselines and targets

### Module 4: Building a business case (30 min)

- [User Guides → Building a Business Case](../end-user-guides/building-a-business-case.md)
- Use a template to structure your business case
- Add narrative and financial sections
- Generate the executive summary view

### Module 5: Sharing and collaboration (15 min)

- [User Guides → Collaboration](../end-user-guides/collaboration.md)
- Share your business case with a colleague
- Add a comment requesting feedback
- Export to PDF

## Assessment

Complete the 20-question quiz in the learning portal. Passing score: 80%.
