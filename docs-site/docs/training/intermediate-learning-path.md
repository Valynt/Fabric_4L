# Intermediate Learning Path

Deepen your ValuePact skills with advanced modeling, stakeholder management, and analytics.

## Who this is for

<span class="vp-badge vp-badge--role">End User</span>
<span class="vp-badge vp-badge--role">Analyst</span>

## Prerequisites

- Completed Beginner Learning Path or equivalent experience
- At least 2 initiatives created in ValuePact

## Learning objectives

After completing this path, you will be able to:

- Build complex driver trees with dependencies
- Manage stakeholder engagement strategically
- Interpret analytics and variance reports
- Configure custom workflows
- Use integrations effectively

## Modules

### Module 1: Advanced value modeling (60 min)

- [Core Concepts → Driver Trees](../core-concepts/roi-calculations.md)
- Build multi-level driver trees
- Configure cross-initiative dependencies
- Use scenario modeling (best/expected/worst case)
- Apply sensitivity analysis

### Module 2: Stakeholder management (45 min)

- [User Guides → Managing Stakeholders](../end-user-guides/managing-stakeholders.md)
- Map influence and interest matrices
- Set up RACI assignments
- Configure engagement tracking
- Use persona-driven messaging

### Module 3: Analytics interpretation (60 min)

- [Analytics → Interpreting Analytics](../analytics/interpreting-analytics.md)
- Read ROI analytics dashboards
- Interpret forecast accuracy metrics
- Use trend analysis for planning
- Compare against benchmarks

### Module 4: Custom workflows (45 min)

- [Workflow Management → Approval Workflows](../workflow-management/approval-workflows.md)
- Configure multi-stage approvals
- Set up escalation rules
- Use automation triggers

### Module 5: Integrations (45 min)

- [Integrations](../integrations/index.md)
- Connect Salesforce or HubSpot
- Configure sync schedules
- Map fields between systems
- Troubleshoot sync issues

## Assessment

Complete the case study exercise and 25-question quiz. Passing score: 85%.
