# Certification Checklists

Requirements and checklists for ValuePact certifications.

## Who this is for

<span class="vp-badge vp-badge--role">End User</span>
<span class="vp-badge vp-badge--role">Admin</span>

## ValuePact User Certification

### Prerequisites

- [ ] Complete [Beginner Learning Path](beginner-learning-path.md)

### Knowledge areas

- [ ] Navigate all four workspaces
- [ ] Create an initiative with stakeholders and metrics
- [ ] Build a basic value model
- [ ] Generate a business case
- [ ] Share deliverables and collaborate

### Assessment

- 20-question quiz
- Passing score: 80%
- Time limit: 30 minutes
- 2 attempts allowed

## ValuePact Analyst Certification

### Prerequisites

- [ ] ValuePact User Certification
- [ ] Complete [Intermediate Learning Path](intermediate-learning-path.md)

### Knowledge areas

- [ ] Build complex driver trees
- [ ] Manage stakeholder influence matrices
- [ ] Interpret analytics and variance reports
- [ ] Configure custom workflows
- [ ] Set up and troubleshoot integrations

### Assessment

- Case study exercise (60 minutes)
- 25-question quiz
- Passing score: 85%
- 2 attempts allowed

## ValuePact Administrator Certification

### Prerequisites

- [ ] ValuePact Analyst Certification
- [ ] Complete [Advanced Learning Path](advanced-learning-path.md)
- [ ] Admin role in a ValuePact tenant

### Knowledge areas

- [ ] Configure SSO and MFA
- [ ] Create custom roles and permissions
- [ ] Design custom workflows and approval gates
- [ ] Use the API for automation
- [ ] Set up governance and audit frameworks
- [ ] Configure branding and custom fields

### Assessment

- Practical exercise: Configure a tenant from scratch (90 minutes)
- 30-question quiz
- Passing score: 90%
- 2 attempts allowed

## Recertification

Certifications expire after 2 years. Recertify by:

- Passing a shortened update quiz (covers new features)
- Or retaking the full certification
