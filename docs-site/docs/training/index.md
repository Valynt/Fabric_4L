# Training

Structured learning paths to build proficiency with ValuePact, from first-time user to platform expert.

## Who this is for

<span class="vp-badge vp-badge--role">End User</span>
<span class="vp-badge vp-badge--role">Admin</span>
<span class="vp-badge vp-badge--role">Executive</span>

## Learning paths

| Path | Duration | Audience | Outcome |
|------|----------|----------|---------|
| [Beginner](beginner-learning-path.md) | 2–3 hours | New users | Navigate the platform, create first initiative, build a basic business case |
| [Intermediate](intermediate-learning-path.md) | 4–6 hours | Regular users | Advanced value modeling, stakeholder management, analytics interpretation |
| [Advanced](advanced-learning-path.md) | 8–10 hours | Power users, admins | Custom workflows, integration setup, governance configuration, API usage |

## Certification

Complete a learning path and pass the associated assessment to earn a ValuePact certification:

| Certification | Prerequisites | Assessment |
|---------------|--------------|------------|
| ValuePact User | Beginner path | 20-question quiz, 80% to pass |
| ValuePact Analyst | Intermediate path | Case study + quiz, 85% to pass |
| ValuePact Administrator | Advanced path | Practical exercise + quiz, 90% to pass |

See [Certification Checklists](certification-checklists.md) for detailed requirements.
