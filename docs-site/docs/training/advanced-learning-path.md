# Advanced Learning Path

Master ValuePact administration, governance, API usage, and platform configuration.

## Who this is for

<span class="vp-badge vp-badge--role">Admin</span>
<span class="vp-badge vp-badge--role">Developer</span>
<span class="vp-badge vp-badge--role">Power User</span>

## Prerequisites

- Completed Intermediate Learning Path or 6+ months active usage
- Admin access to your ValuePact tenant

## Learning objectives

After completing this path, you will be able to:

- Configure SSO, MFA, and security policies
- Design and implement custom workflows
- Use the API for automation and integration
- Set up governance and audit frameworks
- Manage tenant configuration and branding

## Modules

### Module 1: Security configuration (60 min)

- [Administration → Authentication](../administration/security/authentication.md)
- [Administration → SSO](../administration/security/sso.md)
- [Administration → MFA](../administration/security/mfa.md)
- Configure SAML/OIDC integration
- Enforce MFA policies
- Set password complexity rules

### Module 2: User and role management (45 min)

- [Administration → User Management](../administration/user-management/index.md)
- [Administration → Role Management](../administration/role-management/index.md)
- Create custom roles
- Configure permission matrices
- Set up group-based access
- Manage bulk user imports

### Module 3: Custom configuration (60 min)

- [Administration → Configuration](../administration/configuration/index.md)
- Configure custom fields
- Design custom workflows
- Set up notification templates
- Apply branding (logo, colors)

### Module 4: API and automation (90 min)

- [API Overview](../api/overview.md)
- [API → Authentication](../api/authentication.md)
- Authenticate and make API requests
- Build scripts for bulk operations
- Set up webhook integrations
- Handle errors and rate limits

### Module 5: Governance and audit (45 min)

- [Administration → Audit Logs](../administration/security/audit-logs.md)
- [Best Practices → Governance](../best-practices/governance.md)
- Configure audit log retention
- Set up compliance reporting
- Design approval gates
- Document standards

## Assessment

Complete the practical exercise (configure a tenant from scratch) and 30-question quiz. Passing score: 90%.
