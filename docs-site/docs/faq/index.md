## Quick answers

### How do I get started?

Follow the [Quick Start Guide](../getting-started/quick-start-guide.md) for a step-by-step walkthrough from sign-in to your first business case.

### What roles exist and what can they do?

See [User Roles](../getting-started/user-roles.md) for a complete permission matrix.

### How do I invite my team?

Admins can invite users from **Administration → User Management → Invite Users**. See [Invite Users](../administration/user-management/invite-users.md) for details.

### Is my data secure?

Yes. ValuePact uses encryption at rest and in transit, tenant isolation, SOC 2 Type II controls, and regular penetration testing. See [Security FAQ](security-faq.md) for details.

### Can I export my data?

Yes. Use **Deliverables → Export** for PDF reports, or the [API](../api/overview.md) for structured data export.

### How do integrations work?

ValuePact connects to CRM, collaboration, and project management tools via OAuth. See [Integrations](../integrations/index.md) for available connectors.

### What if I need help?

- Search this documentation
- Check [Troubleshooting](../troubleshooting/index.md)
- Contact support@valuepact.ai
- For production issues, open a ticket with severity classification
