# Executive FAQ

## Overview

This page answers the most common questions asked by executives and board members about return on investment (ROI), security posture, and time-to-value.

## Who this is for

- <span class="vp-badge vp-badge--role">Executive</span>
- <span class="vp-badge vp-badge--role">Admin</span>

## Prerequisites

- Familiarity with your organization’s ValuePact initiatives.
- Access to the **Executive Dashboard**.

## Frequently asked questions

### 1. How quickly will we see ROI?

Most customers capture measurable value within the first 90 days. The timeline depends on data quality, executive sponsorship, and the complexity of your initial use case. Organizations with clean Salesforce or HubSpot data typically realize benefits faster because ingestion requires less manual reconciliation.

### 2. Can ValuePact produce board-ready reports?

Yes. The **Executive Dashboard** exports to PowerPoint and PDF with a single click. Each chart includes an evidence trail linking every number to its source system, audit log, and owner. Board members can drill from a summary metric to the underlying business case without leaving the presentation format.

### 3. How do you protect our data?

ValuePact uses Clerk for authentication with support for SAML 2.0 and OIDC single sign-on (SSO). All data is encrypted at rest using AES-256 and in transit via TLS 1.3. The platform is multi-tenant by design; tenant isolation is enforced at the API gateway, database query layer, and graph traversal level. See the [Security FAQ](security-faq.md) for certifications and penetration testing schedules.

### 4. What happens if an employee leaves?

Admins can deactivate the user in seconds. Because ValuePact uses role-based access control (RBAC) synced through Clerk, access revocation propagates immediately. Audit logs retain a permanent record of every action the user took for compliance purposes.

### 5. Is the AI output auditable?

Yes. Every insight generated by Layer 4 (Agentic Workflow Engine) includes a provenance chain. You can view the prompt version, the source data snapshot, and the model used. Layer 5 (Ground Truth) validates structured outputs against TruthObjects to prevent hallucinated claims.

### 6. How do you handle vendor lock-in?

All business cases, value models, and audit trails export to open formats: CSV, JSON, and PDF. API contracts follow OpenAPI 3.1 specifications. You own your data and can extract it at any time without penalty.

### 7. What is the total cost of ownership?

ValuePact pricing is seat-based with optional platform fees for high-volume API usage. There are no hidden ingestion charges. Your customer success manager provides a TCO worksheet during onboarding that includes implementation, training, and first-year support.

## Troubleshooting

??? question "Issue: Executive Dashboard shows no data"
    **Cause:** Initiatives have not been linked to the executive view, or filters are too narrow.
    **Resolution:**
    1. Open **Dashboards & Reporting > Executive Dashboard**.
    2. Click **Configure View** and select the relevant portfolios.
    3. Remove date-range filters that exclude all initiatives.

??? question "Issue: Exported board report is missing charts"
    **Cause:** The browser pop-up blocker intercepted the download, or the export timed out.
    **Resolution:**
    1. Allow pop-ups from `valuepact.ai`.
    2. Reduce the number of visible widgets before exporting.
    3. Use CSV export as a fallback for large datasets.
