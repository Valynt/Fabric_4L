# ValuePact Documentation

Welcome to the ValuePact documentation site.

ValuePact helps teams define, forecast, track, and report business value across initiatives, projects, stakeholders, and outcomes.

## Start here

- [What is ValuePact?](getting-started/what-is-valuepact.md)
- [Quick Start Guide](getting-started/quick-start-guide.md)
- [User Roles](getting-started/user-roles.md)
- [Core Concepts](core-concepts/index.md)

## Main documentation areas

- **Getting Started**: onboarding, navigation, and first steps.
- **Core Concepts**: value realization, business cases, ROI, benefits, forecasts, and actuals.
- **User Guides**: step-by-step workflows for daily users.
- **Dashboards & Reporting**: executive, portfolio, team, and individual reporting.
- **Analytics**: ROI analytics, trend analysis, benchmarking, and interpretation.
- **Workflow Management**: statuses, lifecycle management, approvals, escalations, and automation.
- **Administration**: users, roles, permissions, branding, workflows, notifications, and security.
- **Integrations**: Salesforce, HubSpot, Slack, Teams, Jira, ServiceNow, APIs, and webhooks.
- **API**: authentication, rate limits, errors, pagination, and endpoint documentation.
- **Troubleshooting**: common problems and resolution steps.
- **Best Practices**: governance, adoption, data quality, reporting cadence, and portfolio reviews.
- **Training**: learning paths and certification checklists.
- **Support**: knowledge base templates, escalation guides, and severity matrix.
