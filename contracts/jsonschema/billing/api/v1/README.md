# Billing API Schemas

## Scope
JSON Schema contracts for Billing REST API request and response payloads.

## Owner
platform/billing

## Authoring Direction
`SCHEMA_FIRST` — API schemas are authored by hand in this directory and serve as the source of truth. Backend request/response DTOs and frontend types are derived from these schemas.

## Compatibility
Default: `ADDITIVE_WITHIN_MAJOR`. No breaking changes within a major version.
