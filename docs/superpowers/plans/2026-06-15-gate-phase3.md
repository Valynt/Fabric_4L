# GATE Phase 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire `MemoryGateway` into the agent runtime, record memory accesses in `ReplayRecorder`, make replay snapshot hashes deterministic, and add retrieval-time source blocklisting.

**Architecture:** Reuse the existing Phase 2 `ToolGateway`/`ReplayRecorder` injection in `BaseAgent.run()`. Add a `MemoryGateway` creation step that wraps a caller-provided `retrieval_engine`, injects `ctx["memory_gateway"]`, and feeds the access log into the replay snapshot. Keep all changes additive and behind existing GATE env flags.

**Tech Stack:** Python 3.11+, pydantic, pytest, existing `value_fabric.shared.governance` package, existing `layer4_agents` service.

```python
    def _apply_source_blocklist(
        self,
        result_dict: dict[str, Any],
        override_blocklist: list[str] | set[str] | None = None,
    ) -> dict[str, Any]:
        blocklist = set(override_blocklist) if override_blocklist is not None else self._source_blocklist
        if not blocklist:
            return result_dict

        allowed_entities = [
            e for e in result_dict.get("entities", [])
            if not self._is_blocked(e, blocklist)
        ]
        allowed_ids = {e["id"] for e in allowed_entities}

        allowed_relationships = [
            r for r in result_dict.get("relationships", [])
            if r.get("source") in allowed_ids and r.get("target") in allowed_ids
        ]

        result_dict["entities"] = allowed_entities
        result_dict["relationships"] = allowed_relationships
        return result_dict

    @staticmethod
    def _is_blocked(entity: dict[str, Any], blocklist: set[str]) -> bool:
        source_id = entity.get("source_id") or entity.get("provenance_source")
        return bool(source_id and source_id in blocklist)
```

### Step 1: Update `CONTRACT.md`

Add or update §3.10 and §3.11:

```markdown
### §3.10 Memory Gateway

All retrieval operations initiated by a governed agent MUST flow through `MemoryGateway`. The gateway MUST:

- Compute a canonical `content_hash` of the retrieved result.
- Record `source_lineage` for every retrieved entity.
- Emit a `MEMORY_ACCESS` audit event with `tenant_id`, `agent_id`, `trace_id`, `content_hash`, and `source_lineage`.
- Support a per-run `memory_source_blocklist` to drop poisoned or embargoed source IDs.

Direct calls to `GraphRAGEngine.query()` or `HybridSearch.search()` from agent code are deprecated and will be removed in v3.0.

### §3.11 Replay Recorder

Every governed agent run MUST commit a `REPLAY_SNAPSHOT` audit event on successful completion. The snapshot MUST:

- Include the ABOM manifest hash.
- Include the count and content hashes of tool invocations.
- Include the count and content hashes of memory accesses.
- Use a deterministic canonical hash (`snapshot_hash`) so identical inputs produce identical hashes.
- Be disableable via `AGENT_REPLAY_MODE=disabled` for high-throughput scenarios.
```
