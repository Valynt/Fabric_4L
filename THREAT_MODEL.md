# Threat Model Index

The canonical threat model is maintained in
[docs/security/threat-model.md](docs/security/threat-model.md). This root file
exists only to make the threat model easy to find from repository search,
security reviews, and audit evidence bundles.

The canonical model covers tenant-boundary risks across L1–L6, STRIDE threats,
control mappings, verification evidence, and residual follow-ups. Update that
file for substantive threat model changes; update this index only when the
canonical location changes.
